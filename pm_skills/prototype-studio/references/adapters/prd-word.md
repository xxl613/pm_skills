# PRD Word导出

脚本使用Pandoc解析Markdown，python-docx处理真实OpenXML。依赖通过PATH或`--pandoc`指定，模板可`--reference-doc`指定；不引用旧机器路径、不联网下载依赖。源图片以源目录与`--resource-path`解析。

默认保留首个H1和所有源内容，无额外封面/目录/作者/生成状态。可明确`--drop-first-title`去除首H1。Typora自动image-数字类图注清除，真实图注保留。图片解析失败由Pandoc报错，不能静默漏图。

A4，中文/拉丁字体可参数化，蓝色标题，表格完整六边网格、首行底色/粗体、按内容长度分配列宽，tblGrid与单元格宽度相同。长内容允许换行；不以NoWrap逼长表溢出。

导出后检查ZIP/XML、表格边框、标题样式、列宽。脚本生成的检查只证明结构，不证明打印效果。文档交付需要调用可用的Word/PDF技能渲染并逐页验看，未渲染在报告中明确。

渲染出现中文缺字、方框或空白时，不能记为视觉通过。先核验 DOCX XML 是否保留原文，再检查渲染进程可见的 CJK 字体和 fontconfig 配置；必要时在临时渲染环境指定本机可用字体，或通过 `--font` 选择已确认字体后重新导出。不要为一次渲染改系统字体配置，也不要用结构计数替代中文字的可见完整性。
