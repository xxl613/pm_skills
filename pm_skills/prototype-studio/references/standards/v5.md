## 选用与真源

- 桌面对话优先 `assets/examples/chat-flow-full.html`；执行中和计划编辑分别用同目录对应样例。对话六件（输入台、消息头、用户气泡、拍了拍、完成操作栏、追问建议）复制既有 HTML/CSS 与真实图片，不凭文字重画。
- 桌面历史轨道复制 `assets/components/history-rail.html` 全部结构、CSS、初始化器；它还提供独立可运行入口 `assets/standalone/history-rail.html`。移动端不套桌面轨道。
- 移动对话/弹层优先 `assets/examples-mobile/` 与 `assets/components-mobile/mobile-ui.css`，保留 375 平台体系；桌面 1440 标准与移动页不混用。全页缩放属于宿主选择，不因嵌入局部标准件强加全站缩放。
- `shell/` 与 `shell-mobile/` 保留为源骨架。部分有占位头像或简化内容，不优先于真实完整样例，不作所有交互已实现的证据。
- 原样例与基准是源保全材料。新规范明确纠正的旧冲突按规范执行；未纠正的视觉细节复制实际选定代码，不凭文字重画。源样例存在未接线或不合规的交互，不能以“代码优先”覆盖明确规范。

## 锁定结构与业务槽位

保留所选标准件的类名、字号间距、图标、圆角和交互。允许替换已确认业务文案/对象/状态和用户指定的项目主题槽位；原版快照不改，项目覆盖要限定作用域。局部选用不附带“高校教师”“大明白 V5”的全站产品身份，也不强制 V5 首页或其他页面布局。

头像先保留项目已确认映射；新角色从 media 或 avatars 中选择并固定，不在后续状态换人。只有用户选择 V5 品牌首页时才固定 `media/home-agent-cast.png` 群像。禁止从生成图片里臆造缺失标准图标。

## 对话与交互

- 任务对话按请求、接收/判断、按需派发、执行、产物、完成、后续建议的语义顺序。没有多 Agent 的任务不凭空增加派发。过程状态附于消息头；不展示私有推理链或原始内部日志。
- 消息头名称/时间/状态按样例使用细分隔线及统一辅助字号；一条消息一个说话人。拍了拍接在派发消息末尾，完成操作栏放该轮产物之后，追问是可操作完整问句。
- 完成后的过程折叠/展开、发送、复制、反馈、取消等实际行为由项目接线。静态样例有这个外观不等于功能完成；页面 PRD 必须说明实际状态迁移。
- 桌面历史轨道宽 32、高 168，16 条刻度示范；hover/focus 展开 300×244 面板，query 只接受 01–16，唯一当前项/刻度/aria-current。Escape 收起，焦点保留；可见模态出现时隐藏且所有链接退出 Tab 顺序，关闭后恢复。16 是标准样例容量，不能默认为业务数据库固定记录数。
- 对话中的轻量详情可用卡片/抽屉；移动次级动作采用底部弹层或对应完整页面。业务需要独立列表/详情时由规格决定，不延续旧规范“所有详情不能独立成页”。
- 增删改查依据对象与角色：不要求派生统计量提供人工编辑按钮。危险操作给明确影响说明与确认；取消不改变共享数据；操作完成后所有引用页面按同一数据源更新。

## 结果卡、资源与移动端

对话结果卡用 `components/chat-result-card.html`（`.v5-rcard`），表单/弹窗卡用 `.v5-card`，不要混用。结果卡槽位为类别标签、标题/meta、内容/选项、操作行；生命周期底色来自该组件，卡内主操作近黑、页面级 CTA 品牌色。列表/长文按实际信息组织，不把任意长列表塞入固定高度内滚动卡。

文件场景应明确已选、上传、解析、失败、已发送等适用状态；发送后文件与文字气泡保持独立。移动页保留安全区、顶栏、底部输入台/弹层的对应结构，不能把桌面抽屉压到手机宽度。标准样例内计数、日期、课程、人物和旧文案均是示范，不是项目来源证据。

## 来源与验证边界

所有文件的源路径/源 SHA256/当前 SHA256/改动说明在 [pack.json](../../assets/standards/v5/1.0.0/pack.json)。原始图标、头像、图片和移动渲染代码按原字节保全；file-upload.svg 是原包真实资源。新增独立history入口及重写规范分别记录来源和改动。

`figma-reference` 实际是原技能保留的组件渲染截图，原 Figma 直出图曾丢失；不得称本次从 Figma 新验证。移动 shell 基准含旧来源，不能证明当前移动 B/C 的像素一致性。许可未找到，登记 unknown。

验收需要分别给出：包哈希/本地引用、页面消费绑定、真实交互、选定范围截图与可用基准比较。迁移保全成功只证明没有丢文件。多状态可以在真实可交互页面中切换，同时保留可直达评审状态；不延续“一页一态禁止所有状态切换”的旧限制。
