# 色彩、材质与真实素材

## 功能色与品牌色

项目已有主色和token优先。新体系先定表面、正文/辅助文字、主要动作、选中、focus、错误/警告/成功等语义角色，再选具体色值。主品牌色数量与语义状态/图表系列不是同一个约束，不能为了“单accent”删去必要区分。

检查实际相邻色对比而非凭观感：普通文字以4.5:1为基线，大字按所采用的可访问性标准和真实尺寸判断；重要非文字状态/控件边界也需可辨。错误不能只用红色，增加说明或符号。暗主题单独验证，不能简单反色。

阴影表达浮层或层次，边界表达分组，模糊表达背景退场；都不应只为填空。允许风格决定有无纹理、渐变和圆角，但不能覆盖标准件或损害文字可读性。

## 资产

登记资产在产品中的身份和来源：logo、用户/Agent头像、内容图片、过程插画、图标。优先项目已有/指定标准的真实文件；角色形象保持固定映射。缺关键来源时问清楚，不以假图标、灰圆圈或任意图库图片冒充指定素材。

图片有信息用途才加入。图像生成可补充已授权的插画与探索图，不能生成事实性产品截图、证明材料或伪造业务数据。记录生成/来源性质，最终资产本地化并保留比例、裁切与必要mask。临时远程URL不能作为交付依赖。

图标统一视觉家族、尺寸、线宽和状态。图标按钮仍需要可访问名称；真实标准图标不因为“不要Lucide/不要Inter”等风格偏好被替换。

## 质量判断

看素材是否承载内容、分辨率是否适合显示尺寸、跨页色调/角色是否一致、透明边缘和mask是否正确。没有图片配额、搜索轮数配额或装饰性统计配额。
