# 桌面、移动与预览画布

先区分“设计坐标缩放预览”与“产品响应式布局”。V5或来源复刻若规定1440坐标缩放，遵守该规则，不能将通用断点建议覆盖它。移动专属页用移动结构，不塞入桌面壳层。

通用产品适配从任务出发：导航在宽屏侧栏/顶栏与小屏可达入口之间转换，表格保留关键列并提供详情/合理横向滚动，复杂表单按组堆叠，辅助面板转独立路径或底部弹层。不能所有多列无条件单列，也不能禁止业务需要的局部横向滚动。

固定顶栏、输入台、底部动作留出内容/键盘/安全区。长答案、上传文件、软键盘开启、横屏、字体放大和窄屏都要看实际表现。菜单不能只hover展开，底部弹层应有关闭及可达焦点。

页面目录与PRD评审壳在业务画布外，保持屏幕像素触达与不挤占内容。真实业务截图与Figma捕获排除评审壳；交付原型保留评审能力。

先测试项目目标尺寸，再测至少一个相邻窄/宽尺寸暴露断点问题。不要把只跑固定375截图称为全部设备验证。
