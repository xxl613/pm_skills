# 可选风格参考

这些配方在无指定标准或明确探索时使用，服从任务、内容、可读性和项目DESIGN。每次选择适合的参考，不全量读取；不依风格随机改变业务数据、增加装饰指标或要求每页不同。

- [文档式极简](editorial-minimal.md)：内容阅读、轻量工作空间；追求安静层级与清楚边界。
- [工业印刷与终端](industrial.md)：明确需要工业/技术表达的展示或特定工具；高密度可读性必须保留。
- [玻璃与精密材质](material-depth.md)：品牌展示或局部层级表达；不是业务后台默认风格。
- [品牌展示构图](marketing-composition.md)：落地页、品牌站、故事展示；不能套到表单/工作台/对话页。
