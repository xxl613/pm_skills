# V5 手机 B-m/C-m 规范

当前手机对话/交互的旧声明设计来源为「全自动课程助教 V5」文件 `4t35fBc4I64igQH6qZpIGL`，画布 `6050:5423`；本次没有新取 Figma。代码在 `assets/components-mobile/mobile-ui.css` 与 `assets/examples-mobile/`。桌面 CSS 不应塞进375视口充当手机版。

## 平台与几何

平台由当前用户指定、页面规格、实际画板/宿主证据依序确定；同一项目可同时有桌面和手机，记录到项目逐页规格，不用旧 v5-profile 建档。强证据冲突且改变结构时再询问；可解释的默认必须标明推断。

| 区域 | 基线 |
|---|---|
| 画板 | 375×812；验证目标手机宽度的实际适配，不固定内部横向溢出 |
| 原型系统区 | 59px，灵动岛125×37；旧00/01/02中的44px已过时 |
| 业务顶栏 | 44px；左右40px触达区，图标24px真实SVG |
| 左右内距 | 16px |
| 输入台 | 343×54，左右16，悬浮影；底部安全区34 |
| Home Indicator | 134×5，距底8 |
| 底部弹层 | 顶圆角16，按内容半屏/近全屏；遮罩 .52；关闭触达32 |
| 字体 | 正文16/24、辅助14/22、页标题17/24、重要标题20/32 |

真实iOS/Android/微信宿主已提供系统状态区时，用 `.v5m-screen--hosted` 移除**演示状态区**，业务顶栏和安全区照常。真实宿主的键盘/安全区不能用一张静态键盘图当实现证明。

对话顶栏左返回，中间菜单+Agent名+角色标签，右电话/播报或其他指定动作；历史/反馈/文件选择整页可用居中标题。桌面 nav/drawer/840/920固定列与 viewport-fit 不进入手机主布局；手机 safe区不进入桌面主布局。共用数据、身份和状态语义，分别使用平台结构。

## 页面类型与适用场景

| 类型 | 规则 |
|---|---|
| A-m 门户 | 移动门户+TabBar；一级导航3–5项、激活近黑；只有已指定V5品牌门户才固定群像。当前B/C来源没有新门户真源，沿用门户来源不能声称新画布一致 |
| B-m 对话 | 消息区在顶栏与输入台之间，用户右、Agent左；任务/文件/结果/追问卡适应内容列；二级页有返回，无TabBar |
| C-m 底部弹层 | 资源来源、模式、更多动作、轻量反馈；遮罩下保留对话背景，关闭回触发器，取消不改数据 |
| C-m 独立整页 | Agent/Skill/历史等需要搜索、长列表、持续浏览的内容；保留搜索、列表、返回，不强塞进底部小弹层 |

长表单或复杂查看也可用产品规划的整页，不能执行旧“所有对话旁内容一律sheet”的口径。短选项与长搜索是不同选择依据。手机思考/过程留在消息流，不弹桌面右侧抽屉。

## 所选能力的状态与验收

以下是适用能力所需覆盖；项目没使用该能力则不强行新造页面。状态可在真实界面交互切换，并保留可直达的评审入口。

| 能力 | 应覆盖状态/行为 | 源样例 |
|---|---|---|
| 对话输入 | 空闲、输入展开、可发送、发送中/失败；键盘不挡最后输入/按钮 | `mobile-chat.html`、`mobile-composer.html` |
| 添加资源 | 来源、文件选择、返回/取消、已选文件回填 | `mobile-sheet-add.html` |
| 任务 | 进行、暂停/恢复、终止确认、完成/失败；共用任务数据 | `mobile-task.html` |
| 思考 | 主Agent接收、专员执行、完成；无私有推理泄漏 | `mobile-thinking.html` |
| Agent/Skill | 搜索、无结果、选择、权限/不可用、选择后回输入上下文 | `mobile-agent-skill.html` 的行样式可参考，承载需纠正 |
| 反馈 | 类型、描述、校验、提交/失败/成功、返回 | `mobile-feedback.html` |
| 文件 | 上传七态、生成文件与用户上传区分、查看来源 | `mobile-file.html` |
| 问题/追问 | 单选/自由输入、确认/拒绝或跳过、键盘与取消 | `mobile-followup.html` |
| 历史 | 搜索、会话列表、当前项、选择进入、无结果 | `mobile-history.html` |

状态的具体数据字段、存储/刷新策略与性能决策同步页面PRD；“原型”不是伪报发送/反馈已经落库的理由。

## 保全样例中已经知道的限制

- `mobile-demo.js` 是静态场景渲染器，输入台多为span，搜索多为div，任务数字写死。复制到项目要改成真实输入/搜索与共享数据；点击改按钮“已提交/已确认”不等于已保存业务数据。
- Agent/Skill 源样例使用底部弹层，而更新后的旧09要求长搜索使用整页。本版本明确采用整页规则：仅复用行/搜索视觉，不能把该样例整壳直接当规范合格。
- 手机文件源示例含“右侧填写”桌面文案；应替换为所选手机页面/弹层的真实动作。
- 源演示返回/关闭并不都正确接线；脚本有同名 history 渲染函数，不能直接假定 `history.back()`有效。项目使用明确浏览器history API或已知父路由，并测试直接打开页面时的回退。
- 固定软键盘、等待/暂停视觉、营销文案、emoji占位和日期只是源素材，不是新的业务规范或已验证功能。已存在真实图标可用时按对应图标资源实现。

接入完成必须实测输入/选中/返回/关闭/提交/失败等实际使用路径，并检查触达尺寸、滚动、焦点、键盘遮挡。源截图只给视觉参考。
