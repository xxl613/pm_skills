# V5 1.0.0 标准件规范入口

本目录是这个版本的规范真源，与同包 `assets/` 的真实 HTML/CSS/JS、SVG、PNG 一起复制并锁定。根技能里的 V5 文档只负责选用和导航，不维护第二份详细规则。规范只约束用户选定的页面或区域。

| 选用范围 | 必读规则 | 实现素材 |
|---|---|---|
| 任意 V5 标准件 | [几何与基础组件](geometry-components.md) | `assets/tokens.css` 与对应 component |
| 桌面标准对话/输入台 | [对话交互](conversation.md) | `assets/examples/chat-flow-full.html`；执行/计划编辑用对应样例 |
| 对话结果卡/列表 | [结果卡](result-cards.md) | `assets/components/chat-result-card.html` |
| 手机对话/弹层/列表 | [移动端](mobile.md) + 所选对话/卡片交互规则 | `assets/components-mobile/mobile-ui.css`、`assets/examples-mobile/` |
| 检查/抽取/升级 | [验收与来源覆盖](verification.md) | `pack.json` 与本包检查/样例 |

上述素材路径均相对本包根目录。每个被选组件需要同时取规范、结构、样式、真实资源、适用状态；只复制截图或 HTML 外观不算完成标准件实现。

## 规范、代码和证据的顺序

1. 用户当前明确指定的范围、项目已确认数据与交互决策优先。业务规则属于项目规格，不能从源样例课程名、统计数、固定历史条数推导。
2. 本目录明确解决过的旧规范冲突，以本目录为准。例如手机状态区 59px、长搜索列表用整页、卡片两种合法结构、绿色接收方 mention。
3. 没有明确修正规则的视觉细节，复制所选标准件的现有代码和真实图片。完整成品优先于旧壳层；不要仅凭文字重画。
4. 代码是保全快照，部分按钮未接线、部分静态展示违背更新后的交互规则；这些限制见验收表。复制后必须接上项目状态与数据，并验证。代码外观不能覆盖明确交互要求。

## 可变与锁定

- 锁定：所选组件的层级、类名、布局节奏、图标形象、状态语义、平台体系。项目覆盖须限定在所选范围，不能污染宿主。
- 可替换：已确认名称、文案、数据、Agent 映射，以及用户明确指定的主题变量。引用/字段/状态新增时同步 PRD 和数据合同；不以“保持标准”填假业务值。
- 新组件的抽取需有明确边界、依赖、交互状态和示例。标准包更新要登记新版本及迁移差异；当前项目不会自动升级。
- 复制标准包也会带上本目录，因此日常使用无需旧技能目录、旧项目档案或已归档 references。
