# 记录统计

## 一、页面说明

本页是合成自测中的统计页面，用来核对“全部记录”页面发生新增、修改和删除后，统计数字与记录列表是否保持一致。用户可以从顶部导航进入；记录列表和统计数字只读，不单独保存另一份统计数据。页面底部另有“重置合成测试数据”按钮，用于恢复自测初始数据，会同时影响其他两个页面。

## 二、页面字段逻辑

### 字段：全部记录数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“全部记录”和当前数量。 |
| 字段位置 | 位于页面顶部统计区域的第一张卡片。 |
| 数据来源逻辑 | 根据“全部记录”页面当前保存的所有记录逐条计数。 |
| 展示逻辑 | 没有记录时显示 0；始终等于未完成数量与已完成数量之和。 |
| 操作逻辑 | 只用于查看，不能直接修改；需要在“全部记录”页面维护记录。 |

### 字段：未完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“未完成”和当前数量。 |
| 字段位置 | 位于页面顶部统计区域的第二张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算标记为未完成的记录数量。 |
| 展示逻辑 | 没有未完成记录时显示 0。 |
| 操作逻辑 | 只用于查看；记录状态变化后自动重新计算。 |

### 字段：已完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“已完成”和当前数量。 |
| 字段位置 | 位于页面顶部统计区域的第三张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算标记为已完成的记录数量。 |
| 展示逻辑 | 没有已完成记录时显示 0。 |
| 操作逻辑 | 只用于查看；记录状态变化后自动重新计算。 |

### 字段：当前记录

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | List |
| 页面上显示的文字 | 显示“当前记录”、记录数量以及每条记录的标题和状态；没有记录时显示空状态。 |
| 字段位置 | 位于页面中部统计卡片下方。 |
| 数据来源逻辑 | 来自“全部记录”页面当前保存的完整记录列表。 |
| 展示逻辑 | 展示全部记录，不按状态过滤；其他窗口修改本地测试记录后，本页同步刷新。 |
| 操作逻辑 | 本列表只读。逐条新增、编辑、切换状态和删除都在“全部记录”页面完成；本页底部的自测重置会整体恢复初始记录。 |

## 三、页面整体逻辑

### 逻辑：统计同步

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 页面打开，或“全部记录”页面中的记录发生新增、修改、状态切换、删除和重置时。 |
| 涉及内容 | 全部记录数量、未完成数量、已完成数量和当前记录列表。 |
| 处理逻辑 | 读取同一组测试记录，先计算记录总数，再分别计算未完成和已完成数量，不保存第二份统计结果。 |
| 页面结果 | 三个统计数字与当前列表保持一致；无记录时数字均为 0，并显示空状态。 |
| 对其他页面的影响 | 本页只读取和计算，不修改“全部记录”或“仅未完成记录”页面的数据。 |

### 逻辑：重置合成测试数据

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 用户点击页面底部“重置合成测试数据”时。 |
| 涉及内容 | 全部测试记录、记录状态和三个统计数量。 |
| 处理逻辑 | 清除本轮操作产生的变化，恢复三条初始测试记录，其中两条未完成、一条已完成。 |
| 页面结果 | 显示三条初始记录，三个统计数字恢复为全部 3、未完成 2、已完成 1。 |
| 对其他页面的影响 | “全部记录”和“仅未完成记录”同步显示重置后的记录和统计。 |

## 四、页面状态机

首次打开、刷新或重新进入时，读取当前保存的测试记录：有记录就显示统计结果，没有记录就显示空状态。尚无测试数据时先载入三条初始记录。

### 状态说明

| 状态名称 | 进入条件 | 页面表现 | 可进行的操作 | 离开条件 |
|---|---|---|---|---|
| 显示统计结果 | 当前保存的测试记录至少有一条。 | 显示三个统计数字和完整记录列表。 | 查看统计与记录、重置测试数据，或通过顶部导航进入其他页面。 | 全部记录被删除。 |
| 没有记录 | 当前没有测试记录。 | 三个统计数字均为 0，记录区域显示空状态。 | 在本页重置测试数据，或进入“全部记录”新增记录。 | 新增记录或任一页面重置后出现至少一条记录。 |

### 状态变更

| 当前状态 | 触发动作或事件 | 判断条件 | 变更后状态 | 页面变化 | 对其他页面的影响 |
|---|---|---|---|---|---|
| 显示统计结果 | 共享记录发生变化，或本页重新获得显示 | 变化后仍有记录 | 显示统计结果 | 重新计算三个统计数字并刷新完整列表，页面状态不变。 | 无，此次只读取数据。 |
| 显示统计结果 | “全部记录”删除记录 | 删除后没有任何记录 | 没有记录 | 三个统计数字变为 0，记录区域显示空状态。 | 无，此次只读取数据。 |
| 没有记录 | “全部记录”新增记录，或其他页面重置测试数据 | 变化后至少有一条记录 | 显示统计结果 | 重新显示统计数字和完整记录列表。 | 无，此次只读取数据。 |
| 没有记录 | 本页重新获得显示 | “全部记录”中仍然没有记录 | 没有记录 | 保持三个统计数字为 0 和空状态。 | 无。 |
| 显示统计结果或没有记录 | 点击本页“重置合成测试数据” | 无 | 显示统计结果 | 按本页“重置合成测试数据”逻辑恢复三条初始记录及统计。 | “全部记录”和“仅未完成记录”同步显示重置结果。 |
