# 全部记录

## 一、页面说明

本页是原型工作室的合成自测页面，用来验证新增、查看、修改和删除记录后，多个页面能否显示同一组结果。页面中的三条初始记录和统计数字都是测试内容，不代表真实项目数据；用户从顶部导航进入本页，可以维护测试记录并前往“记录统计”或“仅未完成记录”页面核对变化。

## 二、页面字段逻辑

### 字段：全部记录数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“全部记录”和当前记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第一张卡片。 |
| 数据来源逻辑 | 根据“全部记录”页面当前保存的记录逐条计数；新增一条增加一，删除一条减少一。 |
| 展示逻辑 | 没有记录时显示 0；始终等于未完成数量与已完成数量之和。 |
| 操作逻辑 | 只用于查看，不能直接修改；记录新增、状态变化或删除后自动重新计算，其他统计页面同步显示相同结果。 |

### 字段：未完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“未完成”和当前未完成记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第二张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算当前标记为未完成的记录数量。 |
| 展示逻辑 | 没有未完成记录时显示 0。 |
| 操作逻辑 | 只用于查看；新增记录默认计入未完成，记录被标记为已完成或删除后自动减少。 |

### 字段：已完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“已完成”和当前已完成记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第三张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算当前标记为已完成的记录数量。 |
| 展示逻辑 | 没有已完成记录时显示 0。 |
| 操作逻辑 | 只用于查看；记录被标记为已完成时增加，恢复为未完成或被删除时减少。 |

### 字段：记录标题

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Input；保存后在 List 中以 Label 展示 |
| 页面上显示的文字 | 输入区显示“记录标题”，提示文字为“输入一条测试记录”；列表显示保存后的完整标题。 |
| 字段位置 | 输入框位于页面中部“全部记录”区域顶部；保存后的标题显示在下方记录列表中。 |
| 数据来源逻辑 | 初始标题来自本技能预置的三条合成测试记录；新增或编辑后的标题来自用户在本页输入并成功保存的内容。 |
| 展示逻辑 | 去掉首尾空格后必须为 1 至 80 个字；空标题不能保存。没有记录时显示明确空状态。 |
| 操作逻辑 | 用户可以新增和编辑标题。保存后所有统计页面读取最新标题；取消编辑时保留原内容，保存失败时保留已经输入的文字。 |

### 字段：记录状态

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Status Tag + Button |
| 页面上显示的文字 | 每条记录显示“未完成”或“已完成”及对应的状态切换操作。 |
| 字段位置 | 位于每条记录标题旁边。 |
| 数据来源逻辑 | 初始状态来自预置的合成测试记录；新建记录默认未完成，之后由用户在本页切换。 |
| 展示逻辑 | 状态文字与记录当前状态保持一致；不能只使用颜色区分。 |
| 操作逻辑 | 点击状态操作后只改变当前记录，并立即重新计算三个统计数量；“记录统计”和“仅未完成记录”页面同步变化。 |

### 字段：记录列表

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | List |
| 页面上显示的文字 | 显示全部测试记录的标题、状态以及编辑和删除操作；没有记录时显示空状态。 |
| 字段位置 | 位于页面中部输入区下方。 |
| 数据来源逻辑 | 来自用户在“全部记录”页面新增和维护的同一组本地测试记录；初始三条内容仅用于技能自测。 |
| 展示逻辑 | 始终展示当前全部记录，不因状态过滤；页面重新打开后仍读取同一组测试内容。 |
| 操作逻辑 | 每条记录可以编辑、切换状态或删除。删除前显示记录名称并要求确认；取消删除不产生变化，确认后所有页面同步移除该记录。 |

## 三、页面整体逻辑

### 逻辑：新增记录

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 用户填写记录标题并点击“添加记录”时。 |
| 涉及内容 | 记录标题、记录列表、全部记录数量和未完成数量。 |
| 处理逻辑 | 检查标题不为空且不超过 80 个字；通过后新增一条默认未完成的记录。 |
| 页面结果 | 新记录出现在列表中，输入框恢复为空，全部记录数量和未完成数量各增加一。 |
| 对其他页面的影响 | “记录统计”和“仅未完成记录”页面读取到新增记录及更新后的统计。 |

### 逻辑：重置合成测试数据

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 用户点击“重置合成测试数据”时。 |
| 涉及内容 | 全部测试记录、记录状态和三个统计数量。 |
| 处理逻辑 | 清除本轮操作产生的变化，恢复为三条初始测试记录，其中两条未完成、一条已完成。 |
| 页面结果 | 列表和统计恢复到初始状态。 |
| 对其他页面的影响 | “记录统计”和“仅未完成记录”页面同步显示重置后的结果。 |

## 四、页面状态机

首次打开、刷新或重新进入时，读取当前保存的测试记录：有记录就显示全部记录，没有记录就显示空状态。尚无测试数据时先载入三条初始记录；编辑和删除确认窗口默认关闭。

### 状态说明

| 状态名称 | 进入条件 | 页面表现 | 可进行的操作 | 离开条件 |
|---|---|---|---|---|
| 显示全部记录 | 当前至少有一条记录，且没有打开编辑或删除确认窗口。 | 显示全部记录、三个统计数字和维护操作。 | 新增、编辑、切换状态、删除或重置记录。 | 打开编辑窗口、打开删除确认窗口，或删除最后一条记录。 |
| 编辑记录 | 用户点击某条记录的“编辑”。 | 显示当前标题的编辑窗口，原列表保留在背景中。 | 修改并保存标题，或取消编辑。 | 保存成功或取消编辑。 |
| 确认删除 | 用户点击某条记录的“删除”。 | 显示待删除记录的名称，并要求确认。 | 确认删除或取消删除。 | 用户确认或取消。 |
| 没有记录 | 当前没有任何记录，且没有打开编辑或删除确认窗口。 | 三个统计数字均为 0，列表位置显示“还没有记录，可以添加第一条”。 | 新增记录或重置测试数据。 | 新增记录成功或重置测试数据。 |

### 状态变更

| 当前状态 | 触发动作或事件 | 判断条件 | 变更后状态 | 页面变化 | 对其他页面的影响 |
|---|---|---|---|---|---|
| 显示全部记录 | 填写标题并点击“添加记录” | 标题去掉首尾空格后为 1 至 80 个字 | 显示全部记录 | 按本页“新增记录”逻辑增加记录和统计，清空输入框。 | “记录统计”和“仅未完成记录”同步显示新记录及统计。 |
| 显示全部记录 | 点击“添加记录” | 标题为空或超过 80 个字 | 显示全部记录 | 显示具体错误，保留输入内容；记录和统计不变。 | 无。 |
| 显示全部记录 | 点击记录的“标为完成”或“标为未完成” | 该记录仍然存在 | 显示全部记录 | 该记录在未完成与已完成之间切换，重新计算两个状态数量；总数不变。 | “记录统计”同步状态与数量；“仅未完成记录”相应移除或加入该记录。 |
| 显示全部记录 | 点击某条记录的“编辑” | 该记录仍然存在 | 编辑记录 | 打开编辑窗口并带入原标题。 | 无。 |
| 编辑记录 | 点击保存 | 标题去掉首尾空格后为 1 至 80 个字 | 显示全部记录 | 关闭编辑窗口，列表显示新标题并提示保存成功。 | “记录统计”和“仅未完成记录”同步显示新标题。 |
| 编辑记录 | 点击保存 | 标题为空或超过 80 个字 | 编辑记录 | 编辑窗口保持打开，并显示具体错误；已输入内容保留。 | 无。 |
| 编辑记录 | 点击取消 | 无 | 显示全部记录 | 关闭编辑窗口，原标题不变。 | 无。 |
| 显示全部记录 | 点击某条记录的“删除” | 该记录仍然存在 | 确认删除 | 打开删除确认窗口并显示记录名称。 | 无。 |
| 确认删除 | 点击取消 | 无 | 显示全部记录 | 关闭确认窗口，记录保持不变。 | 无。 |
| 确认删除 | 点击确认删除 | 删除后仍有其他记录 | 显示全部记录 | 关闭确认窗口，移除该记录并重新计算统计数字。 | “记录统计”和“仅未完成记录”同步移除该记录并更新统计。 |
| 确认删除 | 点击确认删除 | 删除的是最后一条记录 | 没有记录 | 关闭确认窗口，三个统计数字变为 0，并显示空状态。 | “记录统计”和“仅未完成记录”同步进入各自的空状态。 |
| 没有记录 | 新增记录并点击“添加记录” | 标题去掉首尾空格后为 1 至 80 个字 | 显示全部记录 | 显示新记录，全部记录和未完成数量各变为 1。 | “记录统计”和“仅未完成记录”同步显示新记录。 |
| 没有记录 | 点击“添加记录” | 标题为空或超过 80 个字 | 没有记录 | 保留空列表并显示具体错误。 | 无。 |
| 显示全部记录或没有记录 | 点击“重置合成测试数据” | 无 | 显示全部记录 | 恢复三条初始记录及对应统计数字。 | “记录统计”和“仅未完成记录”同步显示重置后的结果。 |
