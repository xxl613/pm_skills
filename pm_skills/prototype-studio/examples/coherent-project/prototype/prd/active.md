# 仅未完成记录

## 一、页面说明

本页是“记录统计”页面的未完成筛选状态，用来查看当前仍未完成的测试记录。用户从顶部导航进入；列表只读，筛选不创建另一组记录，也不改变顶部三个统计数字的计算范围。页面底部的“重置合成测试数据”按钮会恢复初始记录，并同步影响其他两个页面。

## 二、页面字段逻辑

### 字段：全部记录数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“全部记录”和全部测试记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第一张卡片。 |
| 数据来源逻辑 | 根据“全部记录”页面当前保存的所有记录逐条计数，不受当前筛选状态影响。 |
| 展示逻辑 | 没有记录时显示 0；始终等于未完成数量与已完成数量之和。 |
| 操作逻辑 | 只用于查看，不能直接修改。 |

### 字段：未完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“未完成”和当前未完成记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第二张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算标记为未完成的记录数量。 |
| 展示逻辑 | 没有未完成记录时显示 0，并与下方筛选列表的数量一致。 |
| 操作逻辑 | 只用于查看；记录状态变化后自动重新计算。 |

### 字段：已完成数量

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | Card + Label |
| 页面上显示的文字 | 显示“已完成”和当前已完成记录数量。 |
| 字段位置 | 位于页面顶部统计区域的第三张卡片。 |
| 数据来源逻辑 | 从“全部记录”页面保存的记录中，计算标记为已完成的记录数量。 |
| 展示逻辑 | 没有已完成记录时显示 0；当前页面虽然只列未完成记录，顶部仍显示全部记录的统计。 |
| 操作逻辑 | 只用于查看；记录状态变化后自动重新计算。 |

### 字段：未完成记录列表

| 说明项 | 具体内容 |
|---|---|
| 字段类型 | List |
| 页面上显示的文字 | 显示“仅未完成记录”、筛选后的数量以及每条未完成记录的标题和状态；没有结果时显示“没有未完成记录”。 |
| 字段位置 | 位于页面中部统计卡片下方。 |
| 数据来源逻辑 | 来自“全部记录”页面当前保存的记录，只保留状态为未完成的内容；筛选结果不单独保存。 |
| 展示逻辑 | 列表数量等于顶部未完成数量。顶部全部记录、未完成和已完成数量仍按所有记录计算。 |
| 操作逻辑 | 本列表只读。逐条修改或删除记录时进入“全部记录”页面；退出筛选时进入“记录统计”页面。本页底部的自测重置会整体恢复初始记录。 |

## 三、页面整体逻辑

### 逻辑：未完成记录筛选

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 用户进入“仅未完成记录”页面，或原有记录状态发生变化时。 |
| 涉及内容 | 未完成记录列表、筛选结果数量和顶部三个统计数字。 |
| 处理逻辑 | 从全部测试记录中筛选当前未完成的记录。顶部统计继续使用全部记录，不能把筛选后的数量当作记录总数。 |
| 页面结果 | 只显示未完成记录；没有未完成记录时显示明确空状态。 |
| 对其他页面的影响 | 筛选只影响当前页面显示，不修改“全部记录”和“记录统计”页面的数据。 |

### 逻辑：重置合成测试数据

| 说明项 | 具体内容 |
|---|---|
| 触发时机 | 用户点击页面底部“重置合成测试数据”时。 |
| 涉及内容 | 全部测试记录、未完成记录列表和顶部三个统计数字。 |
| 处理逻辑 | 恢复三条初始测试记录，其中两条未完成、一条已完成；列表只显示这两条未完成记录。 |
| 页面结果 | 未完成列表显示两条记录，三个统计数字恢复为全部 3、未完成 2、已完成 1。 |
| 对其他页面的影响 | “全部记录”和“记录统计”同步显示重置后的完整记录和统计。 |

## 四、页面状态机

首次打开、刷新或重新进入时，读取当前保存的测试记录并筛选未完成记录：有结果就显示未完成列表，没有结果就显示“没有未完成记录”。尚无测试数据时先载入三条初始记录，再显示其中两条未完成记录。

### 状态说明

| 状态名称 | 进入条件 | 页面表现 | 可进行的操作 | 离开条件 |
|---|---|---|---|---|
| 显示未完成记录 | 当前保存的测试记录中至少有一条未完成记录。 | 列表只显示未完成记录；顶部仍显示全部记录的统计。 | 查看未完成记录、重置测试数据，或通过顶部导航进入其他页面。 | 所有未完成记录被标为已完成或被删除。 |
| 没有未完成记录 | 当前没有未完成的测试记录。 | 列表区域显示“没有未完成记录”，顶部继续显示全部记录的统计。 | 在本页重置数据，或进入“全部记录”新增记录、恢复未完成状态。 | 新增、恢复未完成状态或任一页面重置后出现未完成记录。 |

### 状态变更

| 当前状态 | 触发动作或事件 | 判断条件 | 变更后状态 | 页面变化 | 对其他页面的影响 |
|---|---|---|---|---|---|
| 显示未完成记录 | 共享记录发生变化，或本页重新获得显示 | 变化后仍有未完成记录 | 显示未完成记录 | 重新筛选列表并更新顶部统计，页面状态不变。 | 无，此次只读取数据。 |
| 显示未完成记录 | “全部记录”切换状态或删除记录 | 变化后没有未完成记录 | 没有未完成记录 | 清空筛选列表并显示“没有未完成记录”，顶部统计按全部记录更新。 | 无，此次只读取数据。 |
| 没有未完成记录 | “全部记录”新增记录、恢复未完成状态，或其他页面重置测试数据 | 变化后至少有一条未完成记录 | 显示未完成记录 | 显示最新的未完成记录列表并更新顶部统计。 | 无，此次只读取数据。 |
| 没有未完成记录 | “全部记录”修改或删除已完成记录，或本页重新获得显示 | 仍然没有未完成记录 | 没有未完成记录 | 保持空状态，顶部统计按最新全部记录刷新。 | 无，此次只读取数据。 |
| 显示未完成记录或没有未完成记录 | 点击本页“重置合成测试数据” | 无 | 显示未完成记录 | 按本页“重置合成测试数据”逻辑恢复两条未完成记录，顶部统计恢复为 3、2、1。 | “全部记录”和“记录统计”同步显示重置结果。 |
